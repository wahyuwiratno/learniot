# LearnIOT - Landing Page 🌐

LearnIOT adalah platform pendaratan (landing page) modern yang dirancang khusus untuk mengedukasi masyarakat tentang teknologi *Internet of Things* (IoT). Proyek ini menggabungkan desain minimalis yang elegan dengan fungsionalitas tinggi untuk memberikan pengalaman pengguna yang mulus, terutama pada perangkat mobile.

## 🚀 Teknologi yang Digunakan

Proyek ini dibangun menggunakan ekosistem pengembangan web terbaru untuk memastikan performa dan kemudahan pemeliharaan:

* **React.js** - Framework utama untuk membangun antarmuka pengguna yang reaktif.
* **Vite** - *Build tool* generasi berikutnya yang memberikan pengalaman pengembangan yang sangat cepat.
* **React Bootstrap** - Integrasi framework CSS Bootstrap untuk tata letak yang responsif dan fleksibel.
* **AOS (Animate On Scroll)** - Library untuk memberikan efek animasi transisi yang halus saat pengguna menggulir halaman.
* **Swiper.js** - Implementasi slider testimonial yang interaktif dan ramah perangkat sentuh.
* **FontAwesome** - Digunakan untuk ikon antarmuka dan media sosial yang tajam.

## ✨ Fitur Utama

- **Mobile First Design**: Dioptimalkan secara mendalam untuk perangkat mobile, khususnya telah diuji pada layar Pixel 6.
- **Staggered Animations**: Efek kemunculan kartu kelas secara berurutan (*staggered*) untuk memberikan kesan dinamis.
- **Accordion FAQ**: Bagian tanya jawab yang efisien untuk menghemat ruang layar namun tetap informatif.
- **Testimonial Slider**: Slider otomatis dengan navigasi pagination untuk menampilkan bukti sosial (*social proof*).
- **Minimalist Footer**: Footer elegan yang mencakup navigasi cepat dan tautan profesional pengembang.

## 🛠️ Cara Menjalankan Proyek Secara Lokal

Ikuti langkah-langkah berikut untuk menjalankan proyek ini di mesin lokal Anda:

1.  **Clone Repository**
    ```bash
    git clone [https://github.com/wahyuwiratno/learniot.git](https://github.com/wahyuwiratno/learniot.git)
    ```
2.  **Masuk ke Direktori Proyek**
    ```bash
    cd portfolio-pt2
    ```
3.  **Instal Dependensi**
    ```bash
    npm install
    ```
4.  **Jalankan Server Pengembangan**
    ```bash
    npm run dev
    ```
5.  **Buka di Browser**
    Akses `http://localhost:5173` (atau port yang tertera di terminal Anda).
