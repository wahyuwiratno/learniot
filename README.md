# LearnIOT - Landing Page

LearnIOT adalah platform pembelajaran Internet of Things (IoT) yang dirancang untuk membantu pemula memahami teknologi masa depan. Proyek ini dibangun dengan fokus pada performa, estetika minimalis, dan responsivitas maksimal untuk perangkat mobile.

## 🚀 Teknologi yang Digunakan
* **React.js** - Framework library untuk UI.
* **Vite** - Build tool untuk performa pengembangan yang cepat.
* **React Bootstrap** - Framework CSS untuk tata letak yang responsif.
* **AOS (Animate On Scroll)** - Untuk animasi perpindahan elemen saat scroll.
* **Swiper.js** - Untuk slider testimonial yang interaktif.
* **FontAwesome** - Ikon sosial media dan antarmuka.

## ✨ Fitur Utama
- **Responsive Design**: Dioptimalkan khusus untuk perangkat mobile (seperti Pixel 6).
- **Staggered Animations**: Efek munculnya elemen kelas secara berurutan.
- **Accordion FAQ**: Tanya jawab yang ringkas dan informatif.
- **Testimonial Slider**: Ulasan alumni yang interaktif.
- **Minimalist Footer**: Identitas profesional pengembang (Wahyu Wiratno).
